# Hints

## Requirements

- [Docker](https://www.docker.com/)
- The codeunit GenericMCPServerBackend has to be built before this codeunit, because its build-result is copied into the image. The
  pipeline does that automatically, because GenericMCPServerBackend is declared as a dependent codeunit.

## IDE

Recommended IDE: [Visual Studio Code](https://code.visualstudio.com/) with the Docker-extension.
