# Release notes

## Changes

- Initial version of GenericMCPServer.
- Added the codeunit GenericMCPServerBackend: a backend which offers a MCP-server over HTTP under the route `/API/v1/MCP`. The
  protocol is handled by the MCP-SDK of Microsoft, which is registered in `Program.cs` and whose endpoint is mapped
  there; the transport runs in the stateless mode. The tools it offers are the methods of the `BusinessLogicService`
  which are marked with the `[McpServerTool]`-attribute.
- Added the tools `get_cve_details`, `get_available_maven_versions`, `get_available_nuget_versions`,
  `get_available_pypi_versions` and `get_available_npm_versions`, which are implemented as python-scripts in
  `Resources/Tools`. Every script parses its arguments with `argparse` and checks each of them against a regular
  expression which is anchored at both ends, so a value which does not have the expected format is rejected before it
  is used. The arguments are handed over without a shell and one by one, so a value can not be interpreted as a
  command of its own.
- Added the codeunit GenericMCPServer: a container-image which packages the backend and exposes its MCP-endpoint over HTTP.
  The image contains a python-interpreter, because the scripts which implement tools need one.
- Added an example which starts the built image using docker-compose.
