# GenericMCPServerBackend

GenericMCPServerBackend is the backend for GenericMCPServer.

It hosts the MCP-servers which an administrator declares in a tool-definitions-file: every one of them is reachable
under an address of its own, offers exactly the tools, resources and prompts of its declaration and is used by the
clients whose roles the declaration allows. The codeunit itself contains neither a tool nor a resource nor a prompt.
